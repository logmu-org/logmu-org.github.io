## LogMu R packages

- [logmu](https://r-logmu.logmu.org/): Actuarial mortality experience analysis and modelling
- [datey](https://r-datey.logmu.org/): Exact date and duration arithmetic on an annual grid
- [naxp](https://r-naxp.logmu.org/): Define mappings for alphanumeric codes using expressions
